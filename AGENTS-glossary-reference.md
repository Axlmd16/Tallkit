# Referencia de glosario de AGENTS

| Término | Glosario de origen | Contexto |
|---|---|---|
| ADR | [Glosario técnico](docs/tecnico/glosario-tecnico.md#adr) | Decisiones arquitectónicas duraderas que deben consultarse o actualizarse. |
| OpenSpec | [Glosario técnico](docs/tecnico/glosario-tecnico.md#openspec) | Flujo obligatorio para especificar y aplicar cambios. |
| Monolito modular | [Glosario técnico](docs/tecnico/glosario-tecnico.md#monolito-modular) | Arquitectura que debe preservarse al implementar capacidades. |
| TDD | [Glosario técnico](docs/tecnico/glosario-tecnico.md#tdd) | Secuencia obligatoria para implementar cambios. |
| Lockfile | [Glosario técnico](docs/tecnico/glosario-tecnico.md#lockfile) | Archivos de dependencias reproducibles que deben conservarse. |
| Modelo de dominio | [Glosario del producto](docs/negocio/producto/glosario.md#modelo-de-dominio) | Fuente conceptual que no debe convertirse directamente en tablas. |
| Invariante | [Glosario del producto](docs/negocio/producto/glosario.md#invariante) | Regla que el backend debe preservar. |
| Entidad fiscal | [Glosario del producto](docs/negocio/producto/glosario.md#entidad-fiscal) | Límite para operaciones y documentos económicos. |
| Kardex | [Glosario del producto](docs/negocio/producto/glosario.md#kardex) | Registro trazable de movimientos de inventario. |
