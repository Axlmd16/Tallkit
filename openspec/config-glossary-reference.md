# Referencia de glosario de la configuración OpenSpec

| Término | Glosario de origen | Contexto |
|---|---|---|
| ADR | [Glosario técnico](../docs/tecnico/glosario-tecnico.md#adr) | Decisiones duraderas que deben leerse o registrarse cuando corresponda. |
| OpenSpec | [Glosario técnico](../docs/tecnico/glosario-tecnico.md#openspec) | Flujo que organiza proposal, specs, design y tasks. |
| Monolito modular | [Glosario técnico](../docs/tecnico/glosario-tecnico.md#monolito-modular) | Arquitectura objetivo del backend. |
| TDD | [Glosario técnico](../docs/tecnico/glosario-tecnico.md#tdd) | Disciplina exigida para las tareas de implementación. |
| Atomicidad | [Glosario técnico](../docs/tecnico/glosario-tecnico.md#atomicidad) | Garantía requerida para operaciones sensibles. |
| Idempotencia | [Glosario técnico](../docs/tecnico/glosario-tecnico.md#idempotencia) | Protección frente a solicitudes duplicadas. |
| Concurrencia | [Glosario técnico](../docs/tecnico/glosario-tecnico.md#concurrencia) | Riesgo que las specs y el diseño deben cubrir. |
| Entidad fiscal | [Glosario del producto](../docs/negocio/producto/glosario.md#entidad-fiscal) | Límite estricto de operaciones económicas. |
| Modelo de dominio | [Glosario del producto](../docs/negocio/producto/glosario.md#modelo-de-dominio) | Fuente conceptual obligatoria. |
| Invariante | [Glosario del producto](../docs/negocio/producto/glosario.md#invariante) | Regla de negocio que no puede violarse. |
| Kardex | [Glosario del producto](../docs/negocio/producto/glosario.md#kardex) | Trazabilidad requerida para inventario. |
| Existencia | [Glosario del producto](../docs/negocio/producto/glosario.md#existencia) | Cantidad física controlada en bodega. |
| Disponibilidad | [Glosario del producto](../docs/negocio/producto/glosario.md#disponibilidad) | Cantidad vendible después de reservas activas. |
