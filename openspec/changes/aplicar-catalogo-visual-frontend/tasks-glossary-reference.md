# Referencia terminológica de las tareas

Este documento complementa `tasks.md`. En caso de discrepancia prevalecen las decisiones confirmadas, el modelo de dominio y las specs del cambio.

| Término | Uso en estas tareas |
| --- | --- |
| Adaptación (`A`) | Decisión necesaria para integrar el patrón Figma al producto y que no se atribuye a un nodo inexistente. |
| Evidencia exacta (`E`) | Implementación que debe conservar una referencia Figma estructurada y una comparación visual equivalente. |
| Referencia Figma | Imagen exportada a escala 1 desde el nodo fuente mediante la integración Figma; no es una captura usada para inferir estilos. |
| Actual | Captura reproducible de la implementación obtenida con navegador, viewport, DPR y fuentes fijados. |
| Diff | Resultado de comparar una referencia Figma con una captura de implementación de región equivalente. |
| Baseline aprobado | Evidencia promovida a `approved/` únicamente después de la aceptación visual explícita del usuario. |
| Divergencia | Diferencia no justificada o todavía no aceptada entre la fuente estructurada y la implementación. |
| Estado verificado | Estado sustentado por procedencia, prueba, captura, comparación y aceptación aplicables; nunca un valor global por defecto. |
| Área activable | Caja completa que responde a la interacción, no solamente el glifo o input visual interior. |
| Sidebar desplegado | Variante de 218 px usada desde 1280 px, basada en `4:2`/`4:233`/`4:234`; el breakpoint es una adaptación del producto. |
| Rail compacto | Variante de 80 px basada en `4:344`, usada entre 768 y 1279 px. |
| Contenido neutral | Texto o datos propios del catálogo que sustituyen contenido personal o comercial de la plantilla sin alterar su estructura visual. |
