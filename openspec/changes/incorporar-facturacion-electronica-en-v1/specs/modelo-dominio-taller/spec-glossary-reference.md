# Referencia de glosario de la especificación

| Término | Glosario de origen | Contexto |
|---|---|---|
| Entidad fiscal | [Glosario del producto](../../../../../docs/negocio/producto/glosario.md#entidad-fiscal) | Cada RUC se activa por separado y conserva sus operaciones. |
| Documento interno | [Glosario del producto](../../../../../docs/negocio/producto/glosario.md#documento-interno) | Sigue existiendo y no se presenta como factura. |
| Facturación electrónica | [Glosario del producto](../../../../../docs/negocio/producto/glosario.md#facturación-electrónica) | Pasa a formar parte de V1. |
| Archivo fiscal | [Glosario del producto](../../../../../docs/negocio/producto/glosario.md#archivo-fiscal) | Guarda la copia propia de Tallkit, incluida la prueba real. |
| SRI | [Glosario del producto](../../../../../docs/negocio/producto/glosario.md#sri) | Autoridad que autoriza los comprobantes. |
| Proveedor de emisión | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Empresa que genera, firma y envía el comprobante al SRI. |
| Adaptador de emisión | Nuevo; se incorporará a `docs/tecnico/glosario-tecnico.md` | Pieza que conecta Tallkit con un proveedor. |
| Firma electrónica | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | La conserva el proveedor, no Tallkit. |
| RIDE | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Representación impresa o en PDF del comprobante autorizado. |
| Prueba real supervisada | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Pocas facturas reales previas a la facturación diaria. |
