# Referencia de glosario de la propuesta

| Término | Glosario de origen | Contexto |
|---|---|---|
| Facturación electrónica | [Glosario del producto](../../../docs/negocio/producto/glosario.md#facturación-electrónica) | Pasa a formar parte de V1; su definición se actualiza en este cambio. |
| Entidad fiscal | [Glosario del producto](../../../docs/negocio/producto/glosario.md#entidad-fiscal) | Cada RUC se activa por separado para emitir. |
| RUC artesanal | [Glosario del producto](../../../docs/negocio/producto/glosario.md#ruc-artesanal) | Puede activarse primero; factura a IVA 0 %. |
| RUC comercial | [Glosario del producto](../../../docs/negocio/producto/glosario.md#ruc-comercial) | Espera su RUC definitivo, su firma y la validación del redondeo del IVA. |
| SRI | [Glosario del producto](../../../docs/negocio/producto/glosario.md#sri) | Autoridad que autoriza los comprobantes. |
| Documento interno | [Glosario del producto](../../../docs/negocio/producto/glosario.md#documento-interno) | Sigue existiendo y no es una factura. |
| Archivo fiscal | [Glosario del producto](../../../docs/negocio/producto/glosario.md#archivo-fiscal) | Guarda la copia propia de los XML; la prueba real también se archiva. |
| ADR | [Glosario técnico](../../../docs/tecnico/glosario-tecnico.md#adr) | `ADR-0010` recibe una actualización y `ADR-0013` queda para el cambio 3. |
| OpenSpec | [Glosario técnico](../../../docs/tecnico/glosario-tecnico.md#openspec) | Flujo que ordena este cambio y los que dependen de él. |
| Proveedor de emisión | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Empresa que genera, firma y envía el comprobante al SRI. No es el proveedor de mercadería. |
| Adaptador de emisión | Nuevo; se incorporará a `docs/tecnico/glosario-tecnico.md` | Pieza que conecta Tallkit con un proveedor, sin que el resto del sistema lo conozca. |
| Activación por RUC | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Habilitación separada de cada RUC para facturar en la operación diaria. |
| Prueba real supervisada | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Pocas facturas reales para comprobar la autorización del SRI, antes de habilitar la facturación diaria. |
| RIDE | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Representación impresa o en PDF del comprobante electrónico autorizado. |
| Firma electrónica | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Archivo que identifica legalmente al emisor; la conserva el proveedor, no Tallkit. |
| Matriz de normas | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Documento que relaciona cada norma con su fuente oficial y su estado de verificación. |
