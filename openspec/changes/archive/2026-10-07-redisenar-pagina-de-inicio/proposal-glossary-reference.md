# Referencia terminológica

| Término | Glosario de origen | Contexto |
|---|---|---|
| Entidad fiscal | `docs/negocio/producto/glosario.md` | Cada indicador económico del inicio pertenece a una sola. |
| RUC comercial | `docs/negocio/producto/glosario.md` | Ámbito de repuestos: ventas, proformas, entradas y sus cobros. |
| RUC artesanal | `docs/negocio/producto/glosario.md` | Ámbito de servicios: mantenimientos y sus cobros. |
| Mantenimiento | `docs/negocio/producto/glosario.md` | Los abiertos se cuentan entre los pendientes. |
| Proforma | `docs/negocio/producto/glosario.md` | Las vigentes próximas a vencer y los borradores se cuentan entre los pendientes. |
| Venta de repuestos | `docs/negocio/producto/glosario.md` | Las de contado sin cobrar y los borradores se cuentan entre los pendientes. |
| Crédito | `docs/negocio/producto/glosario.md` | Condición que origina parte del saldo por cobrar; no es un medio de pago. |
| Pago | `docs/negocio/producto/glosario.md` | Dinero cobrado que alimenta el gráfico de los últimos 7 días. |
| Retención recibida | `docs/negocio/producto/glosario.md` | Reduce el saldo, pero no cuenta como dinero cobrado. |
| Saldo pendiente | `docs/negocio/producto/glosario.md` | Valor calculado que muestra el bloque «Por cobrar». |
| Permiso efectivo | `docs/negocio/producto/glosario.md` | Decide qué bloques e indicadores recibe cada persona. |
| Cuentas por cobrar | `docs/negocio/producto/glosario.md` | Lista a la que lleva cada indicador de «Por cobrar». |
| Contrato OpenAPI | `docs/tecnico/glosario-tecnico.md` | Se amplía con las consultas de solo lectura del resumen. |
| Evidencia visual | `docs/tecnico/glosario-tecnico.md` | Respalda que la página sigue el sistema visual Tallkit. |
