# Referencia terminológica

| Término | Glosario de origen | Contexto |
|---|---|---|
| Entidad fiscal | `docs/negocio/producto/glosario.md` | Cada indicador económico pertenece a una sola y se muestra separado. |
| RUC comercial | `docs/negocio/producto/glosario.md` | Ámbito de los indicadores de ventas, proformas y cobros de repuestos. |
| RUC artesanal | `docs/negocio/producto/glosario.md` | Ámbito de los indicadores de mantenimientos y cobros de servicios. |
| Permiso efectivo | `docs/negocio/producto/glosario.md` | Decide qué bloques e indicadores entrega el servidor. |
| Mantenimiento | `docs/negocio/producto/glosario.md` | Las órdenes registradas o reabiertas se cuentan como abiertas. |
| Proforma | `docs/negocio/producto/glosario.md` | Se cuentan las vigentes por vencer y los borradores. |
| Venta de repuestos | `docs/negocio/producto/glosario.md` | Se cuentan las de contado sin cobrar y los borradores. |
| Crédito | `docs/negocio/producto/glosario.md` | Las operaciones a crédito no cuentan como contado sin cobrar. |
| Pago | `docs/negocio/producto/glosario.md` | Los pagos vigentes alimentan los cobros de los últimos siete días. |
| Pago combinado | `docs/negocio/producto/glosario.md` | Efectivo y transferencia de un mismo pago se suman en su día. |
| Retención recibida | `docs/negocio/producto/glosario.md` | Reduce el saldo, no cuenta como dinero cobrado y tiene su pendiente de comprobante. |
| Saldo pendiente | `docs/negocio/producto/glosario.md` | Valor que muestra el bloque «Por cobrar». |
| Cuentas por cobrar | `docs/negocio/producto/glosario.md` | Lista de destino cuyo total debe coincidir con el indicador. |
| Estado de pago | `docs/negocio/producto/glosario.md` | Determina si una operación de contado sigue sin cobrar. |
