# Referencia de glosario de la propuesta

| Término | Glosario de origen | Contexto |
|---|---|---|
| Entidad fiscal | `docs/negocio/producto/glosario.md` | Cada uno de los dos RUC; cada una tiene como máximo un logotipo vigente. |
| RUC comercial | `docs/negocio/producto/glosario.md` | Su logotipo encabeza la venta (COM-VEN) y el ingreso de mercadería (COM-ING). |
| RUC artesanal | `docs/negocio/producto/glosario.md` | Su logotipo encabeza el comprobante de servicios (ART-SER). |
| Logotipo de entidad fiscal | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Imagen opcional que identifica visualmente a una entidad fiscal en sus comprobantes internos. No se versiona y es distinta del logotipo de Tallkit. |
| Tallkit | `docs/negocio/producto/vision.md` | Nombre y logotipo del sistema; en la hoja del comprobante queda como mención discreta. |
| Administrador | `docs/negocio/producto/glosario.md` | Único rol que sube, cambia o quita logotipos. |
| Documento interno | `docs/negocio/producto/glosario.md` | Comprobante numerado por las series internas; no es factura electrónica. |
| Facturación electrónica | `docs/negocio/producto/glosario.md` | Fuera de alcance: el logotipo no se aplica a documentos fiscales ni XML. |
| Placa de RUC | `docs/negocio/producto/glosario.md` | Pieza de la ficha de entidad junto a la que se añade la fila «Logo». |
| Modal | `docs/tecnico/glosario-tecnico.md` | Forma de subir o cambiar el logotipo. |
| Notificación temporal (toast) | `docs/tecnico/glosario-tecnico.md` | Confirma que el logotipo se guardó o quitó. |
| Idempotencia | `docs/tecnico/glosario-tecnico.md` | Un reintento de carga no duplica efectos. |
| OpenSpec | `docs/tecnico/glosario-tecnico.md` | Flujo del cambio. |
