# Referencia de glosario del diseño

| Término | Glosario de origen | Contexto |
|---|---|---|
| ADR | [Glosario técnico](../../../../docs/tecnico/glosario-tecnico.md#adr) | `ADR-0010` recibe una actualización; `ADR-0013` queda para el cambio 3. |
| Monolito modular | [Glosario técnico](../../../../docs/tecnico/glosario-tecnico.md#monolito-modular) | El módulo `fiscal` no cambia; la emisión se agregará en él. |
| Facturación electrónica | [Glosario del producto](../../../../docs/negocio/producto/glosario.md#facturación-electrónica) | Su definición se actualiza. |
| Documento interno | [Glosario del producto](../../../../docs/negocio/producto/glosario.md#documento-interno) | Las reglas que lo separan de una factura se mantienen. |
| Archivo fiscal | [Glosario del producto](../../../../docs/negocio/producto/glosario.md#archivo-fiscal) | Su bloqueo productivo sigue activo en el código. |
| Proveedor | [Glosario del producto](../../../../docs/negocio/producto/glosario.md#proveedor) | Se distingue del proveedor de emisión. |
| Referencia fiscal | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Nombre que sustituye a «referencia fiscal futura» en el modelo de dominio. |
| Proveedor de emisión | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Sistema externo que genera, firma y envía el comprobante. |
| Adaptador de emisión | Nuevo; se incorporará a `docs/tecnico/glosario-tecnico.md` | Pieza que conecta Tallkit con un proveedor. |
| Matriz de normas | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Documento con filas `NOR-*` que citan los cambios de emisión. |
| Prueba real supervisada | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Excepción que el código todavía no implementa. |
