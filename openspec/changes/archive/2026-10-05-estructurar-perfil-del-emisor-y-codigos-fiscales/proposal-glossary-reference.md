# Referencia de glosario de la propuesta

| Término | Glosario de origen | Contexto |
|---|---|---|
| Entidad fiscal | `docs/negocio/producto/glosario.md` | Cada uno de los dos RUC; el perfil del emisor se declara por entidad y nunca se comparte. |
| RUC artesanal | `docs/negocio/producto/glosario.md` | Entidad del taller; sus datos reales confirmados motivan la calificación artesanal con vencimiento. |
| SRI | `docs/negocio/producto/glosario.md` | Autoridad fiscal y origen del esquema de factura 2.1.0; sin conexión en este cambio. |
| Preparación fiscal | `docs/negocio/producto/glosario.md` | Expediente local versionado cuya instantánea conserva, en las preparaciones nuevas, el emisor en campos estructurados. |
| Preparación local | `docs/negocio/producto/glosario.md` | Datos fiscales congelados localmente; recibe los impedimentos nuevos de código, descripción y tarifa. |
| Servicio | `docs/negocio/producto/glosario.md` | Trabajo del taller sin existencia física; recibe un código propio. |
| Producto | `docs/negocio/producto/glosario.md` | Bien inventariable; su código interno se limita a 25 caracteres. |
| Perfil del emisor | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Condiciones tributarias declaradas de una entidad fiscal con valores cerrados, vigencia y fundamento. |
| Régimen tributario | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Clasificación del contribuyente ante el SRI: General, RIMPE Emprendedor o RIMPE Negocio Popular. |
| Calificación artesanal | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Reconocimiento vigente del artesano, con número y vencimiento, que sustenta la tarifa 0 % de sus servicios. |
| Agente de retención | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Contribuyente al que el SRI obliga a retener impuestos al pagar; se declara con su número de resolución. |
| Código de servicio | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Identificador visible, único e inmutable de un servicio, usado como código de línea del comprobante. |
| Impedimento | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Causa identificada que deja una preparación en borrador sin completarla con datos ficticios. |
