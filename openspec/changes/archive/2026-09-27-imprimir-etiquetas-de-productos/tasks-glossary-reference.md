# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| Producto | `docs/negocio/producto/glosario.md` | Registro consultado, seleccionado y representado por una etiqueta. |
| Presentación | `docs/negocio/producto/glosario.md` | Cantidad y unidad transportadas por la proyección y mostradas en la etiqueta. |
| Código interno | `docs/negocio/producto/glosario.md` (Producto) | Identificador textual y contenido exacto del código de barras. |
| Etiqueta de producto | `docs/negocio/producto/glosario.md` | Unidad que se compone, previsualiza e imprime. |
| RUC comercial | `docs/negocio/producto/glosario.md` | Ámbito único de la identidad visible de la etiqueta. |
| Logotipo de entidad fiscal | `docs/negocio/producto/glosario.md` | Imagen comercial opcional cuya carga se prepara antes de imprimir. |
| Code 128 | `docs/tecnico/glosario-tecnico.md` | Codificador propio, sus vectores y su SVG verificable. |
| API REST | `docs/tecnico/glosario-tecnico.md` | Proyección GET no paginada de productos filtrados. |
| Contrato OpenAPI | `docs/tecnico/glosario-tecnico.md` | Esquema de la ruta `label-data` y del nombre visible comercial. |

No se introducen términos nuevos; los nombres de módulos, componentes y funciones son identificadores técnicos locales.
