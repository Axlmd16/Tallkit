# Referencia de glosario de la propuesta

| Término | Glosario de origen | Contexto |
|---|---|---|
| Entidad fiscal | `docs/negocio/producto/glosario.md` | Cada uno de los dos RUC; la operación la determina y nombra la pestaña que sustituye a «Identidades fiscales». |
| SRI | `docs/negocio/producto/glosario.md` | Autoridad fiscal y fuente primaria de catálogos; sin conexión en este cambio. |
| Forma de pago | `docs/negocio/producto/glosario.md` | Forma declarada del comprobante según la Tabla 24; se combina, se sugiere desde los cobros o la forma predeterminada y es distinta de los cobros reales. |
| Crédito | `docs/negocio/producto/glosario.md` | Condición interna de saldo; no se traduce a un código de la Tabla 24 y en esta fase no se captura plazo. |
| Documento interno | `docs/negocio/producto/glosario.md` | Comprobante numerado que no es factura electrónica. |
| Preparación local | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Datos fiscales revisados y congelados localmente; no es factura, no está firmada ni enviada al SRI. |
| Borrador fiscal | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Preparación todavía editable que se revisa con la configuración vigente. |
| Pendiente de emisión | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Situación de una preparación local sin emisión electrónica realizada. |
| Punto predeterminado | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Punto de emisión de una entidad que se usa por defecto al preparar. |
| Catálogo oficial | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Códigos del SRI versionados con fuente, vigencia, estado e incorporación. |
| Forma de pago predeterminada | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Forma habilitada que el Administrador designa por entidad y que se sugiere cuando no hay cobros que cubran el total. |
