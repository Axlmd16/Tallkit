## Convenciones

- **Pruebas:** «TDD» significa escribir primero la prueba que falla por la razón esperada (dinero, permisos, aislamiento por negocio). «Al final» es una prueba por flujo al cerrar el grupo. «Sin prueba» es lint, tipos y revisión visual.
- **Comandos:** backend `cd backend && uv run pytest <ruta>`; frontend `cd frontend && npx vitest run <ruta>`. Se ejecutan solo las pruebas relacionadas al cerrar cada grupo; la suite completa solo si el titular la pide.
- **Cierre de cada grupo:** `cd frontend && npm run lint && npm run typecheck` y, si se tocó el backend, `cd backend && uv run ruff check . && uv run mypy src` (los comandos reales de `make backend-check`).
- No se crean commits sin autorización del titular.
