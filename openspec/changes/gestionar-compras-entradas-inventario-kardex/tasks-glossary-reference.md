# Referencia terminológica de las tareas

| Término | Glosario de origen | Contexto |
|---|---|---|
| TDD | [Técnico](../../../docs/tecnico/glosario-tecnico.md#tdd) | Prueba que falla, implementación mínima y refactorización en cada grupo. |
| Idempotencia | [Técnico](../../../docs/tecnico/glosario-tecnico.md#idempotencia) | Recibos de comando y reintentos compatibles de compras e inventario. |
| Transacción atómica | [Producto](../../../docs/negocio/producto/glosario.md#transacción-atómica) | Confirmación conjunta de documento, numeración, movimientos y auditoría. |
| Ingreso de mercadería | [Producto](../../../docs/negocio/producto/glosario.md#ingreso-de-mercadería) | Documento de compra que se recibe completo al confirmar. |
| Kardex | [Producto](../../../docs/negocio/producto/glosario.md#kardex) | Consulta cronológica por corte estable con saldos completos. |
| Movimiento de inventario | [Producto](../../../docs/negocio/producto/glosario.md#movimiento-de-inventario) | Registro inmutable que explica cada variación de existencia. |
| Movimiento inverso | [Producto](../../../docs/negocio/producto/glosario.md#movimiento-inverso) | Compensación vinculada que conserva el original. |
| Costo promedio ponderado | [Producto](../../../docs/negocio/producto/glosario.md#costo-promedio-ponderado) | Valoración actualizada en las entradas con residuo conservado. |
| Ajuste de inventario | [Producto](../../../docs/negocio/producto/glosario.md#ajuste-de-inventario) | Corrección justificada con vista previa y confirmación explícita. |
| Existencia | [Producto](../../../docs/negocio/producto/glosario.md#existencia) | Saldo operativo conciliable con el Kardex, nunca negativo. |
| Bodega | [Producto](../../../docs/negocio/producto/glosario.md#bodega) | Única bodega comercial de V1 donde se reciben las líneas. |
| Presentación | [Producto](../../../docs/negocio/producto/glosario.md#presentación) | Unidad completa contada en cantidades enteras, sin fraccionar envases. |
