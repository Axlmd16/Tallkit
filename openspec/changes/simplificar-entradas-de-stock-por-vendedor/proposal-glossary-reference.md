# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| Administrador | `docs/negocio/producto/glosario.md` | Rol que conserva la anulación de entradas y la consulta de costos y valoración. |
| Costo promedio | `docs/arquitectura/modelo-dominio.md` §4 | Valor unitario ponderado que una entrada sin costo no debe alterar. |
| Existencia | `docs/arquitectura/modelo-dominio.md` §4 | Cantidad física que aumenta al confirmar una entrada. |
| Ingreso de mercadería | `docs/negocio/producto/glosario.md` | Operación que este cambio simplifica; en la propuesta se denomina también entrada de stock. |
| Kardex | `docs/arquitectura/modelo-dominio.md` §4 | Historia inmutable que registra cada entrada y su anulación. |
| Presentación | `docs/arquitectura/modelo-dominio.md` §4 | Unidad cerrada en la que se cuentan las cantidades recibidas. |
| Proveedor | `docs/negocio/producto/glosario.md` | Dato que pasa de obligatorio a opcional en la entrada. |
| Referencia externa | `docs/arquitectura/modelo-dominio.md` §5.2 | Número o descripción del documento del proveedor, ahora opcional y sin unicidad. |
| RUC comercial | `docs/negocio/producto/glosario.md` | Entidad fiscal a la que pertenecen las entradas y la serie COM-ING. |
| Vendedor | `docs/negocio/producto/glosario.md` | Rol que recibe los permisos de consultar, registrar y confirmar entradas. |
