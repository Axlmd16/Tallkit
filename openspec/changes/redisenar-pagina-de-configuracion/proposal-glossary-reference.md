# Referencia de glosario de la propuesta

| Término | Glosario de origen | Contexto |
|---|---|---|
| Entidad fiscal | `docs/negocio/producto/glosario.md` | Cada uno de los dos RUC; se muestran lado a lado y se eligen con dos opciones visibles en *Facturación electrónica*. |
| RUC comercial | `docs/negocio/producto/glosario.md` | Ámbito con tono propio; agrupa COM-ING, COM-PRO y COM-VEN. |
| RUC artesanal | `docs/negocio/producto/glosario.md` | Ámbito con tono propio; agrupa ART-SER. |
| Administrador | `docs/negocio/producto/glosario.md` | Único rol con acceso a la configuración. |
| Bodega | `docs/negocio/producto/glosario.md` | Bodega única de V1, presentada como ficha breve. |
| Impuesto | `docs/negocio/producto/glosario.md` | Vigencias por entidad presentadas en tabla cronológica. |
| Secuencial | `docs/negocio/producto/glosario.md` | Último número de cada serie, en tipografía monoespaciada. |
| Documento interno | `docs/negocio/producto/glosario.md` | Numerado por las series internas; no es factura electrónica. |
| Facturación electrónica | `docs/negocio/producto/glosario.md` | Sección con subsecciones anidadas en la navegación; la emisión sigue no habilitada. |
| Preparación local | `docs/negocio/producto/glosario.md` | Estado «Lista para preparación local» y aviso permanente conservado. |
| Punto predeterminado | `docs/negocio/producto/glosario.md` | Causa típica de pendiente enlazada a su subsección. |
| Forma de pago SRI | `docs/negocio/producto/glosario.md` | Subsección *Formas de pago SRI*; sin cambios de regla. |
| Catálogo oficial | `docs/negocio/producto/glosario.md` | Sus códigos y versiones pasan a «Información avanzada». |
| Placa de RUC | Nuevo; se incorporará a `docs/negocio/producto/glosario.md` | Pieza visual que muestra el RUC monoespaciado con su etiqueta. |
| Modal | `docs/tecnico/glosario-tecnico.md` | Única forma de editar en la configuración rediseñada. |
| Drawer | `docs/tecnico/glosario-tecnico.md` | Descartado para editar. |
| Notificación temporal (toast) | `docs/tecnico/glosario-tecnico.md` | Confirma los guardados; no hay mensajes de guardado automático. |
| OpenSpec | `docs/tecnico/glosario-tecnico.md` | Flujo del cambio. |
