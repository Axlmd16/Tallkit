# Referencia terminológica de las tareas

| Término | Glosario de origen | Contexto |
|---|---|---|
| TDD | [Técnico](../../../docs/tecnico/glosario-tecnico.md#tdd) | Prueba que falla, implementación mínima y refactorización en cada grupo. |
| Idempotencia | [Técnico](../../../docs/tecnico/glosario-tecnico.md#idempotencia) | Recibos de comando, UUID estable de cada hecho y reintentos compatibles. |
| Transacción atómica | [Producto](../../../docs/negocio/producto/glosario.md#transacción-atómica) | Confirmación conjunta de documento, numeración, salidas, dinero y auditoría. |
| Venta de repuestos | [Producto](../../../docs/negocio/producto/glosario.md#venta-de-repuestos) | Operación comercial que este cambio implementa de extremo a extremo. |
| RUC comercial | [Producto](../../../docs/negocio/producto/glosario.md#ruc-comercial) | Ámbito exclusivo de las ventas, cobros y correcciones implementados. |
| Documento interno | [Producto](../../../docs/negocio/producto/glosario.md#documento-interno) | Comprobante imprimible con aviso de no autorización del SRI. |
| Pago | [Producto](../../../docs/negocio/producto/glosario.md#pago) | Dinero aplicado a una sola venta confirmada, con partes por medio real. |
| Abono | [Producto](../../../docs/negocio/producto/glosario.md#abono) | Cobro parcial admitido únicamente en la condición de crédito. |
| Crédito | [Producto](../../../docs/negocio/producto/glosario.md#crédito) | Condición de venta sin vencimientos, cuotas ni intereses. |
| Saldo pendiente | [Producto](../../../docs/negocio/producto/glosario.md#saldo-pendiente) | Valor derivado de E, P y R, nunca almacenado como dato editable. |
| Estado de pago | [Producto](../../../docs/negocio/producto/glosario.md#estado-de-pago) | Estado derivado e independiente del estado de la venta. |
| Cuenta por cobrar | [Producto](../../../docs/negocio/producto/glosario.md#cuenta-por-cobrar) | Consulta comercial de deuda y antigüedad sin mora ni vencimiento. |
| Anulación | [Producto](../../../docs/negocio/producto/glosario.md#anulación) | Corrección conservadora que preserva número, líneas e historia. |
| Devolución | [Producto](../../../docs/negocio/producto/glosario.md#devolución) | Corrección de cantidades y valores con inspección de aptitud. |
| Reembolso | [Producto](../../../docs/negocio/producto/glosario.md#reembolso) | Registro del dinero efectivamente devuelto para liquidar un exceso. |
| Kardex | [Producto](../../../docs/negocio/producto/glosario.md#kardex) | Historia inmutable de las salidas de venta y los reingresos aptos. |
| Movimiento de inventario | [Producto](../../../docs/negocio/producto/glosario.md#movimiento-de-inventario) | Efecto físico publicado por la confirmación o la devolución. |
| Costo promedio ponderado | [Producto](../../../docs/negocio/producto/glosario.md#costo-promedio-ponderado) | Valoración que absorbe los reingresos aptos sin reescribir la historia. |
| Existencia | [Producto](../../../docs/negocio/producto/glosario.md#existencia) | Saldo operativo protegido contra valores negativos al confirmar. |
| Presentación | [Producto](../../../docs/negocio/producto/glosario.md#presentación) | Unidad completa vendida en cantidades enteras. |
