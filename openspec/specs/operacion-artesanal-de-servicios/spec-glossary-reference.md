# Referencia de glosario

| Término | Glosario de origen | Contexto |
|---|---|---|
| Reserva de mantenimiento | [Glosario del producto](../../../docs/negocio/producto/glosario.md#reserva-de-mantenimiento) | Cantidad apartada por la venta abierta vinculada; no es salida ni Kardex. |
| Disponibilidad | [Glosario del producto](../../../docs/negocio/producto/glosario.md#disponibilidad) | Existencia menos reservas vigentes. |
| Documento interno | [Glosario del producto](../../../docs/negocio/producto/glosario.md#documento-interno) | Comprobante de venta u operación artesanal; no es factura del SRI. |
| Crédito | [Glosario del producto](../../../docs/negocio/producto/glosario.md#crédito) | Condición que permite saldo; no es medio de pago. |
| Pago | [Glosario del producto](../../../docs/negocio/producto/glosario.md#pago) | Importe aplicado a un solo documento de un solo RUC. |
| Saldo pendiente | [Glosario del producto](../../../docs/negocio/producto/glosario.md#saldo-pendiente) | Derivado del exigible y los pagos efectivos. |
| Estado de pago | [Glosario del producto](../../../docs/negocio/producto/glosario.md#estado-de-pago) | Pendiente, parcial o pagado, independiente del estado operativo. |
| Preparación local | Nuevo término de `docs/negocio/producto/glosario.md` | Estado visible desde la operación artesanal; no es factura. |
| Pendiente de emisión | Nuevo término de `docs/negocio/producto/glosario.md` | Situación mostrada junto a la preparación local. |
