# Referencia terminológica de existencias y ajustes

| Término | Glosario de origen | Contexto |
|---|---|---|
| Existencia | [Producto](../../../docs/negocio/producto/glosario.md#existencia) | Cantidad real reconstruible desde movimientos. |
| Bodega | [Producto](../../../docs/negocio/producto/glosario.md#bodega) | Única ubicación habilitada. |
| Movimiento de inventario | [Producto](../../../docs/negocio/producto/glosario.md#movimiento-de-inventario) | Efecto confirmado y trazable. |
| Kardex | [Producto](../../../docs/negocio/producto/glosario.md#kardex) | Historia que explica el saldo. |
| Ajuste de inventario | [Producto](../../../docs/negocio/producto/glosario.md#ajuste-de-inventario) | Corrección de una diferencia física comprobada. |
| Costo promedio ponderado | [Producto](../../../docs/negocio/producto/glosario.md#costo-promedio-ponderado) | Valoración y conservación de residuos. |
| Movimiento inverso | [Producto](../../../docs/negocio/producto/glosario.md#movimiento-inverso) | Reversión segura de carga o ajuste. |
