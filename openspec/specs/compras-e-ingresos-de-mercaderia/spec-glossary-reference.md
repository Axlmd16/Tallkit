# Referencia terminológica de compras e ingresos

| Término | Glosario de origen | Contexto |
|---|---|---|
| Ingreso de mercadería | [Producto](../../../docs/negocio/producto/glosario.md#ingreso-de-mercadería) | Documento de compra con recepción completa. |
| Bodega | [Producto](../../../docs/negocio/producto/glosario.md#bodega) | Destino único comercial de las entradas. |
| Servicio | [Producto](../../../docs/negocio/producto/glosario.md#servicio) | Concepto excluido de productos inventariables. |
| Presentación | [Producto](../../../docs/negocio/producto/glosario.md#presentación) | Unidad completa recibida, independiente del contenido. |
| Costo promedio ponderado | [Producto](../../../docs/negocio/producto/glosario.md#costo-promedio-ponderado) | Valoración actualizada por entradas. |
| Movimiento inverso | [Producto](../../../docs/negocio/producto/glosario.md#movimiento-inverso) | Compensación de una compra anulada. |
