# Referencia de glosario

| Término | Glosario de origen | Contexto |
|---|---|---|
| Administrador | `docs/negocio/producto/glosario.md` | Único rol que declara el perfil del emisor y ve el aviso de vencimiento. |
| Bodega | `docs/negocio/producto/glosario.md` | Ubicación única habilitada para el inventario de V1. |
| Documento interno | `docs/negocio/producto/glosario.md` | Representación numerada que no equivale a una factura electrónica. |
| Entidad fiscal | `docs/negocio/producto/glosario.md` | Ámbito del perfil; cada una declara sus propias condiciones. |
| Impuesto | `docs/negocio/producto/glosario.md` | Tarifa configurada por entidad y período de vigencia. |
| RUC artesanal | `docs/negocio/producto/glosario.md` | Entidad fiscal de operaciones económicas de servicios. |
| RUC comercial | `docs/negocio/producto/glosario.md` | Entidad fiscal de ingresos, proformas y ventas. |
| Secuencial | `docs/negocio/producto/glosario.md` | Número monotónico, único y no reutilizable dentro de una serie. |
| Forma de pago | `docs/negocio/producto/glosario.md` | Distinción entre datos fiscales y cobros efectivos. |
| Crédito | `docs/negocio/producto/glosario.md` | Condición de venta, no medio de pago. |
| Punto predeterminado | Nuevo término de `docs/negocio/producto/glosario.md` | Punto usado por defecto al preparar datos fiscales. |
| Catálogo oficial | Nuevo término de `docs/negocio/producto/glosario.md` | Códigos del SRI versionados con fuente, ficha, descarga, vigencia y estado. |
| SRI | `docs/negocio/producto/glosario.md` | Origen del esquema que fija los valores admitidos; sin conexión ni verificación. |
| Logotipo de entidad fiscal | `docs/negocio/producto/glosario.md` | Logotipo opcional del emisor, incorporado por `logotipos-por-ruc`. |
| Preparación local | `docs/negocio/producto/glosario.md` | Función que el perfil habilita o bloquea según su estado. |
| Perfil del emisor | `docs/negocio/producto/glosario.md` | Condiciones tributarias de una entidad declaradas con valores cerrados. |
| Régimen tributario | `docs/negocio/producto/glosario.md` | General, RIMPE Emprendedor o RIMPE Negocio Popular; determina la leyenda. |
| Calificación artesanal | `docs/negocio/producto/glosario.md` | Condición con número, organismo y vencimiento obligatorio. |
| Agente de retención | `docs/negocio/producto/glosario.md` | Condición que, si aplica, exige número de resolución de hasta 8 dígitos. |
| Impedimento | `docs/negocio/producto/glosario.md` | Causa que bloquea preparar una factura; ya no incluye el régimen de negocio popular. |
| Correspondencia tributaria | `docs/negocio/producto/glosario.md` | Relación de un impuesto interno con su tarifa oficial; su cambio se programa a futuro. |
| Negocio Popular | `docs/negocio/producto/glosario.md` | Valor del régimen tributario que no cobra IVA y puede emitir comprobantes electrónicos de forma voluntaria. |
| Tarifa programada | `docs/negocio/producto/glosario.md` | Tarifa interna que rige desde una fecha futura sobre el mismo impuesto. |
