# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| Venta | `docs/negocio/producto/glosario.md` | Operación comercial directa de repuestos del RUC comercial. |
| Cobro | `docs/negocio/producto/glosario.md` | Hecho de dinero recibido que se aplica a una sola venta. |
| Abono | `docs/negocio/producto/glosario.md` | Cobro parcial de una venta a crédito. |
| Crédito simple | `docs/negocio/producto/glosario.md` | Condición de venta sin vencimiento, cuotas ni intereses. |
| Cuentas por cobrar | `docs/negocio/producto/glosario.md` | Deuda cobrable comercial, separada del exceso por reembolsar. |
| Devolución | `docs/negocio/producto/glosario.md` | Corrección de cantidades vendidas con reingreso solo de lo apto. |
| Reembolso | `docs/negocio/producto/glosario.md` | Desembolso efectivo del exceso pagado, registrado como hecho. |
| Entidad fiscal | `docs/negocio/producto/glosario.md` | Ámbito comercial de todas las pruebas; nunca mezclado con el artesanal. |
| Idempotencia | `docs/tecnico/glosario-tecnico.md` | Reintento seguro mediante clave de transporte e identidad estable de operación. |
| OpenSpec | `docs/tecnico/glosario-tecnico.md` | Marco que gobierna los 105 escenarios cubiertos. |
| Retención recibida | `docs/negocio/producto/glosario.md` | Valor retenido por el cliente que reduce el saldo sin ser dinero cobrado; término nuevo del cambio de retenciones. |
