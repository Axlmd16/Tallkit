# Glossary Reference

| Term | Source Glossary | Context |
|---|---|---|
| Presentación | `glosario.md` | Unidad completa incluida en inventario y venta. |
| Entrada de stock | `glosario.md` | Ingreso de mercadería simple que registra el Vendedor. |
| Sin costo registrado | `glosario.md` | Existencia sin valor conocido, distinta del costo cero. |
| Kit | `glosario.md` | Producto comprado que puede desarmarse explícitamente. |
| Consumo interno | `glosario.md` | Salida para uso del taller. |
| Reposición por corrección | `glosario.md` | Salida sin cargo atribuible al taller. |
| Facturación electrónica | `glosario.md` | Incluida en V1 por `DP-034` (sección 3.12). |
| Proveedor de emisión | `glosario.md` | Empresa externa que genera, firma y envía el comprobante al SRI. |
| Activación por RUC | `glosario.md` | Habilitación separada de cada entidad fiscal para facturar. |
| Prueba real supervisada | `glosario.md` | Pocas facturas reales previas a la facturación diaria. |
| RIDE | `glosario.md` | Versión legible del comprobante electrónico autorizado. |
| Firma electrónica | `glosario.md` | La conserva el proveedor de emisión, no Tallkit. |
| Matriz de normas | `glosario.md` | Relaciona cada obligación con su fuente oficial y su estado. |
