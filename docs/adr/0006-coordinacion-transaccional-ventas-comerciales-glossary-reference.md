# Referencia de glosario

| Término | Glosario de origen | Contexto |
|---|---|---|
| Transacción atómica | [Glosario del producto](../../docs/negocio/producto/glosario.md#transacción-atómica) | Confirmación conjunta de efectos comerciales. |
| Idempotencia | [Glosario técnico](../../docs/tecnico/glosario-tecnico.md#idempotencia) | Reintentos sin duplicar hechos ni efectos. |
| Reembolso | [Glosario del producto](../../docs/negocio/producto/glosario.md#reembolso) | Desembolso efectivo del exceso pagado, registrado como hecho y no como orden bancaria. |
| Cuentas por cobrar | [Glosario del producto](../../docs/negocio/producto/glosario.md#cuentas-por-cobrar) | Deuda comercial cobrable derivada de hechos, separada del exceso por reembolsar. |
