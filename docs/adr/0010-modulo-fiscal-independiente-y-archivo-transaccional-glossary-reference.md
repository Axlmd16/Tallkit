# Referencia terminológica — ADR-0010

Usar las definiciones de [glosario del producto](../negocio/producto/glosario.md) para entidad fiscal, documento interno, preparación fiscal, archivo fiscal, evidencia fiscal externa, solicitud de corrección fiscal y estado oficial.

La actualización de `DP-034` usa [proveedor de emisión](../negocio/producto/glosario.md#proveedor-de-emisión), [prueba real supervisada](../negocio/producto/glosario.md#prueba-real-supervisada) y [adaptador de emisión](../tecnico/glosario-tecnico.md#adaptador-de-emisión).
